# v0.20 撮影レビュー記録（新入生と締め＋実機レイアウト修正）

## レビュー基準の変更（本バージョンの前提）

- **主対象を iPhone 15 Pro 横画面の CSS ビューポート 932×430 に変更**した（従来の PC Chromium 1060×600 は補助に格下げ）。
- 経緯： v0.19 公開直後、Takada が実機で週次画面のレイアウト崩れ（場面パネルが活動カード列に重なり、右の情報カードや会話とも衝突して文字が読めない）を発見した。1060×600 は実機より縦に約170px 長く、縦に要素を積む画面の重なり・はみ出しを検出できていなかった。
- 監査方式も強化した（shoot.js）：
  - ページ全体の寸法（document のスクロール寸法）がビューポートを超えたら「doc-overflow」として検出する（新設）。
  - 重なり判定の対象をボタンだけでなく .card / .wscene / .log / .actionbar / .strip / .cmpcard / .banner / table.cmp 等の主要可視要素に広げた（祖先・子孫の関係は除外。モーダルとトーストは対象外）。
  - あらすじモーダルは閉じてから撮影する（背後の画面が監査対象）。

## 再現（修正前・現行 v0.19 相当＋parts のみ）

repro.js（932×430）で週次画面を計測し、ユーザーの指摘を数値で再現した（repro_report.json、screenshots/repro_*.png はモーダル越しの参考画像）。

- .wscene（場面）が 65→245px なのに対し上段（.lay2）は 65→188px。**場面の最小高さ 180px が上段をはみ出し、活動カード列（198→340px）に約47px 重なっていた**。
- 右カラムは情報カード＋会話カード＋ログの最小高さ合計が上段を超え、ログが実質 26px 高まで潰れていた（会話がある週はログが 321→347px に押し下げ）。
- 旧監査で検出できなかった理由： はみ出し判定がスクロール祖先でクリップした「可視矩形」ベースで、場面×カードの重なりはボタン同士でなかったため。

## 修正（実機レイアウト）

1. **週次画面**（最優先・ユーザー指示どおりの構造変更）
   - 場面は「背景として敷く」箱に限定： 固定レイアウト内では .wscene の min-height:180px を解除し、上段の残り高さに収める（CSS の定義順で負けないよう上書きは後方の節に配置）。
   - 会話は右カラムのカードから**場面下部の半透明バー**（.wdlgbar、背景＋半透明カードの重なりだけに限定）へ移動。バーには position:relative を付け、絶対配置の背景の下に潜らないようにした（矩形は正しいのに見えない問題を目視で発見して修正）。
   - 情報カードは圧縮形（.winfo： 疲労メーター＋「怪我人 n人／次の試合」の1行サマリー）。
   - 低丈メディアクエリ（横画面かつ max-height:520px）を新設し、タイトル・カード・ステータスバーを詰める。
   - 修正後の実測（932×430）: scene = 上段と完全一致（65→229px)、活動カード 239→344px、ステータスバー 354→420px、会話バーは場面内 172→220px。重なりゼロ。
2. **対戦確認**： 同じ病巣（固定要素の合計がカラムを突き抜け、編成/スキップボタンがアクションバーに重なる。doc は 932×500）を発見。戦術とキッカー＆マークを**1枚のスクロールカードに統合**し、右カラムは「統合カード（内部スクロール）＋編成ボタン＋スキップ＋注記」だけにした。
3. **目標設定**： doc が 932×450（20px 超過）。左の説明カードを内部スクロール化して解消。
4. **シーズン締め**： 卒業写真が結果カードに押されて帯状（約35px）に潰れていた（設計意図は「卒業が主役」）。バナーの高さ比率を固定（カラムの32%）し、結果カードを内部スクロール化。写真は約95px の帯で表示されるようになった。
5. **新入生紹介**： 実装当初、左カラムにバナーを縦積みしたら帯状に潰れたため、左は情報カード1枚に統一した（主役は右の新入生カード列）。

## 監査結果（修正後）

- 932×430 で全19画面（タイトル／ガイド／目標／月頭指示×2／週次×4／選手データ×2／記録室／対戦確認／編成／試合／シーズン締め／勧誘カード／勧誘比較／新入生紹介）＋補助 1060×600 で3画面（週次会話／勧誘比較／新入生紹介）の**計22画面で、はみ出し・重なり・doc 超過すべてゼロ**（report.json、errors 0)。
- HUD は全画面 45px の1行を維持。

## 画面ごとの所見（様式・見た目）

- 週次（会話つき）: 場面下部の会話バー（立ち絵＋名前＋セリフ）が背景に溶けず読める。9枚の活動カードは全て完全表示でタップ可能。
- 勧誘（カード）: 候補・特別枠に能力ミニ行（総合＋6能力のランク併記）と特能・性格タグが入り、成功率の内訳（基本／部の格／評判／候補の実力／OB紹介／調整）が読める。能力ミニ行は右カラム幅では7項目が2行に折り返す場合がある（崩れではなく折り返しとして許容）。
- 勧誘（比較）: 立ち絵＋名前の列ヘッダー、ポジション／体格／性格／特能／総合＋6能力／成功率／寸評／獲得ボタンまでが1表に収まり、内部スクロールで全行に届く。上部帯（strip）は 932 幅ではタブが2段目に回るが、情報の欠落はない。
- 新入生紹介： 立ち絵＋入部区分バッジ＋能力＋特能＋寸評のカードが並び、卒業演出（シーズン締め）と対になる見せ場になった。左の内訳（スカウト/特別枠／一般）も収まっている。
- 月頭指示（成長レポートつき）: レポート自体は濃緑ボード＋ランク変動表示で良好。ヒーロー内の「最近の出来事」グラスカードは内部スクロール（.herolog）のため 430 高では途中表示になるが、スクロールで全文に届く（重なり・はみ出しではない）ため今回は様式として許容し、記録に留める。
- 試合： 実況=左／選択肢=右、カットイン、スコアが収まっている。
- 選手データ・編成・記録室・ガイド: 内部スクロール＋固定ボタンで収まっている。
