# review_v29 — v0.29（v1.4）「見た目の作り直し（パワプロ系の参照画像の様式へ）」監査・確認記録

作成：2026-11-01（Claude Code）。発端は Takada がパワプロ系の画面3枚（練習メニュー・選手データ・成長レポート）を示しての指示
「ここら辺を参考に全体的なデザインを作り直して！ 時間かかっても大丈夫だから細かい部分まで気を使ってやってみて！」。
進め方は、リポジトリに入れた frontend-design スキル（`.claude/skills/frontend-design`）の手順：題材から色・字・形の決まりを作る →
無難な既定値になっていないか見直す → 組む → スクショで自己批評。

**表示だけの変更**で、ゲームの数値・判定・乱数消費・セーブ形式・localStorage キーは変えていない（下の「ソーク同値性」と qa_v29 で確認）。

**計画の見直しで変えたこと**（スキルが挙げる「生成っぽい既定値」と照らした）：
- v1.3 は同じ角丸・同じぼかし影のガラス調カードを全画面に並べ、地は色付きの黒（`#101410`）だった（スキルの挙げる既定値の 4・5）。
  → 盤面は紺の輪郭と固い影、角の丸みは階層ごと（盤面 12・札 5〜7・ピル 99）、地は空（昼）と夜空（ナイター）。
- 色を飾りに使わない：グラデーションの飾りは空と照明だけ。札の色はすべて意味（ランク・組・系統・役割）を運ぶ。
- 2書体は役割をはっきり分ける：Dela Gothic One は数字と看板だけ。本文・ボタン・札は M PLUS Rounded 1c。

## 変更点

1. **@skin 節（`v02/style.css` の末尾、約 28KB）**：上の決まりを全画面に当てる上書き層。トークンは `:root`、ダークは
   `prefers-color-scheme: dark` で差し替え。HUD・盤面・見出し・ボタン・タブ・セレクト・選手一覧・詳細・週次（活動カード・
   推奨札・状態の帯）・成長レポート・試合前・試合（スコアボード・カットイン）・タイトル・スロット・比較表・トースト・
   キーボードのフォーカス表示。
2. **和文フォントの埋め込み（`tools/embed_fonts.py`）**：game.js と index.html に出てくる文字＋かな・記号の基本セット（1465字）に
   subset した woff2 を data URI で style.css の `@fonts` 節に入れる。M PLUS Rounded 1c Medium（188KB、400〜600 に割り当て）・
   ExtraBold（202KB、700〜900）・Dela Gothic One（143KB）。どちらも SIL OFL 1.1（予約フォント名なし）、ライセンス文は
   `v02/fonts/`、遊び方のクレジットにも表記。play.html は 3.38MB → 4.13MB。
3. **game.js（表示のみ）**：HUD の日付を「年目」と「月」の札に分割（textContent は従来どおり）／選手一覧とメンバー編成の名前を
   ポジションの組の色札に（`posGroupCls`）／練習カードに系統の `data-k`／成長レポートの役割チップを色分け（`r-focus`・`r-start`・
   `r-bench`）、名前札を組の色に、能力名を白い札に／クレジットにフォントを追加／バージョン表記 v1.4。
4. **寸法を変えない工夫**：枠を 1px 太くした盤面は内側の余白を 1px 減らす。ボタンの輪郭は inset の影で太らせる。
   ボタンの行の高さを 1.2 に固定（M PLUS Rounded 1c の normal は 1.485 で、そのままだとボタン1段ごとに約 4px 高くなる）。
   週次の情報欄とログを1枚の盤面にまとめ、間の 8px を返す。
5. **iOS 版の public を同期**（`npm run sync`）。

## 監査で見つけたこと

- **選手一覧の横はみ出し**：作り直しの途中、iPhone の帯（CSS 幅 760〜960px）で選手一覧の右端の列（疲労・信頼）が最初から
  隠れ、横にスクロールしないと見えないのをスクショで見つけた。従来の監査は、縦に流すリストが横にもはみ出す場合を数えて
  いなかった。→ `shoot.js` に **hscroll**（スクロール領域の scrollWidth が clientWidth を超える）を追加し、
  iPhone の帯では身長・体重の列と小さな立ち絵を省き（詳細のプロフィールにある）、リストの列を広げ、mini 級では文字を詰めた。
- **ボタンが高くなる**：フォントを替えただけで、全ボタンが1段ごとに約 4px 高くなった（行の高さ normal＝1.485 のため）。
  ボタン列の多い画面ほど縦に詰まる。→ `button { line-height: 1.2; }`。
- **全角等幅の約物**：M PLUS Rounded 1c は palt（約物の詰め）を持たないため、句読点の分だけ行が伸び、mini 級で
  チュートリアルの帯と会話の文が1行多く折り返した。→ 狭い所だけ字間を詰め、文字を 11.5px に。
- **小さな見切れ**：週の見出しの行の高さ 1.25 で字の上下が欠けた（30画面）→ 1.35。推奨札の折り返し → nowrap。
  15 Pro の選手一覧でランクの数字の左余白がはみ出した → 961px 以上だけに。
- 監査は `document.fonts.ready` を待ってから撮る（埋め込みフォントの読み込み前に測ると字幅が違う）。全画面で fontsLoaded=true。

## 未対応・気になる点

- iPhone の帯では選手一覧に身長・体重の列が出ない（詳細のプロフィールで見られる）。
- M PLUS Rounded 1c は約物が全角のまま。行が伸びる所は字間で吸収したが、長い文を足すときは mini 級で確かめる。
- 新しい漢字をゲームの文に足したら `tools/embed_fonts.py` を流し直す（subset に無い字は端末の書体で出る）。qa_v29 が検出する。
- play.html は 4.13MB（フォント 0.71MB を含む）。上限は 4.5MB。
