# review_v26 — v0.26（v1.1）「実プレイの指摘を受けた手直し」監査・確認記録

作成：2026-10-30（Claude Code、Takada の依頼）。発端は Claude Code が v1.0 を実ブラウザ（932×430）で
約2.5シーズン通しプレイした感想のうち、Takada が「直して」と指定した3点と、追加生成された場面イラスト3枚。

## 変更点（数値・判定式は無変更。セーブ形式・localStorage キーも不変）

1. **勝負どころの成功率を段階の目安で表示**：`（成功率の目安 95%）` → `（成功率の目安 ◎）`。
   ◎=80%以上／○=60〜79%／△=40〜59%／×=40%未満（色つき）。境界は従来表示の%四捨五入と同じ値で判定。
   判定は従来どおり `c.p`。判定値は `data-p` に残り、QA／ソークの「最適寄り」駆動はこれを読む（画面には出ない）。
   ガイドの用語集に「成功率の目安」を追加。
   - 実プレイで見えていた問題：序盤は 95%／78%／95% のように数値が並び、迷わず最大値を押すだけになっていた。
2. **おまかせの練習選択**：練習の週は「方針一致のカード」と「スタメン平均が最も低い能力のカード」を交互に選ぶ。
   休養・ビデオ分析・メンタルの割り込み条件は不変。⭐おすすめ表示も同じ判定（autoWeekKey）。
   - 実プレイで見えていた問題：方針（既定スタミナ）を変えずにおまかせで2年回すと、卒業生が
     「パワー S95・スタミナ S94、パス・キック E〜F」に偏った（autoWeekKey が方針一致カードしか選ばない）。
3. **名前**：名字・名前とも 20→100 種。在籍部員＋直近24件の生成分と名字が重ならないよう、重なったら
   乱数を追加で使わずに名簿の次の名字へずらす（1試行の乱数消費は従来どおり2回）。
   相手校固定エースの名字は名簿から除外。代替わりエース名は先頭20個（ACE_NAME_N）で作り、既存セーブで不変。
   - 実プレイで見えていた問題：18人の部員に清水が4人、龍之介が3人。
4. **場面イラスト3枚**（冬の早朝練習・練習場・部室、ChatGPT 生成 1774×887 PNG → 1600×800 JPEG、240〜256KB）。
   - 冬：12月・1月の月頭指示（MONTH_PHOTOS 8・9・10）。試合月の週次は従来どおり試合 SVG。
   - 練習場：試合の無い5・7・9月（MONTH_PHOTOS 1・3・5）の月頭指示と週次。
   - 部室：年初の目標画面のヒーロー背景。
   - 4月（桜）・6月（梅雨）・10〜11月（秋）は季節 SVG のまま。
   - 既存5枚の原画は style.css の data URI から v02/img/ に復元（バイト一致）。
5. **ビルド**：icon-512.png が無い時は icon-256.png（v1.0 の play.html から書き出した埋め込みアイコン）を使う。
   v1.0 のソース＋この build_play.py で v1.0 の play.html とバイト単位で同一の出力になることを確認。
6. **バージョン表記** v1.1（title／meta／タイトル画面／ガイド）。
