# Road_to_HANAZONO

高校ラグビー育成ゲーム。弱小公立高校ラグビー部の監督になって、選手を育て、花園（全国高等学校ラグビーフットボール大会）を目指す。

- 企画メモ: [DESIGN.md](DESIGN.md)
- 試作 v0: `proto/` フォルダ（`proto/index.html` をブラウザで開くと遊べる）

## 試作 v0 で遊べること

- 1シーズン（4月〜11月）、架空の選手18名を自動生成
- 毎月、練習方針と重点育成選手を選んでチームを強化（ランダムイベントあり）
- 試合は「ハイライト選択式」：勝負どころでモール／展開／キックなどを監督が判断
- 練習試合＋花園予選（準々決勝・準決勝・決勝）。決勝に勝てば花園出場決定
- セーブはブラウザの localStorage に自動保存

## 開発方針

まず Web で試作して手ざわりを確かめ、良ければ iOS（App Store）へ本開発を移す。
