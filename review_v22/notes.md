# v0.22 撮影レビュー notes（デザイン・スリム化＋場面イラスト拡充）

主対象は iPhone 15 Pro 横画面 932×430（従来どおり）。監査ツール `shoot.js` に
**「枠内コンテンツの見切れ検出」を新設**し、はみ出し・重なり・見切れの3点で監査した。

## きっかけ（ユーザーの実機フィードバック）

月頭指示画面の実機スクリーンショット付きで指摘：
「何でもかんでも枠にはめようとするからどんどん使えるスペースが減っているように感じる。
もはや文字は見えてないとこすらある。もっとスリムなデザインが必要だね」
実例＝成長レポートが固定枠の中で下半分見切れ／「最近の出来事」バーが潰れて読めない／
セレクトボックス内の文字が切れている。従来監査（はみ出し＋重なり）では検出できていなかった。

## 新設した見切れ検出（detector）

- `clip-y` / `clip-x`：スクロール前提でない要素で scrollHeight/Width > clientHeight/Width
  （アニメーション変換で scroll 寸法が膨らむため、計測前にアニメーション凍結スタイルを注入）
- `report-clip`：`.grboard`（レポート類）はスクロール可能でも全量が収まらなければ不合格
  （要約・レポート類を黙って見切れさせるのは不可、という原則の実装）
- `crushed-scroll`：スクロール枠にあふれがあるのに clientHeight < 44px（潰れて読めない状態）
- `select-truncate`：選択中 option のテキストを canvas で実測し、表示可能幅
  （clientWidth − 32px のシェブロン余地）を超えたら不合格
- 除外の調整：場面背景レイヤー（.herobg/.wscenebg）と UI の重なりは「背景＋半透明カード」の
  正規の重ね方として重なり判定から除外。絵文字のみの要素はグリフ都合の clip として除外

## 主な変更（詳細は DESIGN.md の v0.22 改訂履歴）

- 成長レポート：月頭指示内の小枠を廃し、レポート月は専用レイアウト（全幅 board）で表示。
  確認ボタンは「確認した（◯月の指示へ）」。fx-grow の行ライズは初出時のみ維持
- 月頭指示：グラス2枚（要約／出来事）を1枚に統合＋罫線区切り。カラム比を .92fr/1.08fr に拡大、
  ラベル1行化、セレクト文言の短縮（ユニット=対象→能力／重点=性格・特能なし／強度=倍率のみ／
  主将=⭐名前＋信頼／校風=短ラベル ETHOS.s 新設）
- 入れ子解消：週次 .winfo 無枠化、対戦確認スカウティングを罫線セクション化、
  目標選択・ガイド・記録室・勧誘比較を .flatbox（無枠）化、全体のパディング／角丸を一段スリム化
- 場面背景の拡大：目標・勧誘・新入生紹介の左カラムをヒーローパネル化（場面背景＋グラス1枚）。
  勧誘の卒業生リストのみグラス内スクロール。勧誘の導入文・寸評は主情報が初回表示で
  完結するよう短縮（成功率の内訳表示とガイドに情報は残置）
- 写真の受け口：PHOTO_SCENES 登録表＋未登録キーの SVG フォールバック。今夜生成の
  冬・練習場・部室は「CSS 写真クラス追加＋登録＋MONTH_PHOTOS 対応付け」の3点で組み込み可能
  （存在しないファイルへの参照は作っていない）
