# v0.17 実ブラウザレビュー（Chromium 横向き 1060×600）

対象：v02/play.html（v0.17）。撮影スクリプト：`shoot.js`（本編17画面）＋ `shoot_extra.js`（成長レポート／ダークモード）、
結果：`report.json` / `report_extra.json`、画像：`screenshots/`。

## 結果サマリー
- コンソールエラー／ページエラー：**なし**（report.errors = []）。
- 全17画面＋追加2画面で **docSW=1060 / docSH=600**（ドキュメントはみ出しゼロ）。
- 監査（スクロールパネル内でクリップされる要素を除外した「可視矩形」同士の判定）で、
  ボタン・セレクト・カード等の **衝突（重なり）ゼロ**。
- HUD は全画面で **高さ45px の1行**（v0.16 までは2行に折り返していた）。

## v0.16 既存事象の解消確認
- 対戦確認画面（予選決勝・帝都）：v0.15／v0.16 で docSH=612（12px はみ出し）だったものが **600 に解消**。
  vs カードを内部スクロール化し、バナーを固定比率（32%）にしたため。スカウティング・因縁・弱点ヒントは
  カード内スクロールで全て読める（`10_prematch.png`）。花園（雨写真）も同様に 600（`14_prematch_hana.png`）。
