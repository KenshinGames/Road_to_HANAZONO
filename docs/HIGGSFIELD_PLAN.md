# Higgsfield 試作プラン — Road to HANAZONO のキャラ絵を AI 生成に差し替える検証

作成：2026-10-29 ／ 予算上限：20,000円（Takada 決定）／ 対象：#47 Road to HANAZONO（Web版 v1.0 完成済み）

## 1. 試作の目的（答えるべき問い）

立ち絵（現行はコード生成 SVG、本人の評価 2/10）を生成 AI に差し替える路線が成立するかを、小さく実測する。

- Q1 画風の統一：イラスト調のキャラ6人を並べて、同じ作品の絵に見えるか
- Q2 同一キャラの一貫性：同じキャラの別カット（対比画面用・カットイン用）で顔が保てるか
- Q3 組み込み適性：ラスター絵を対戦確認「キーマン対比」と試合カットインに入れて、932×430／932×380 で崩れないか
- Q4 採用単価：使える絵1枚あたりの実コスト（クレジット消費と歩留まり）
- Q5 商用条件：有料プランの生成物をゲーム（将来の App Store 公開含む）に使えるか、規約の確認

## 2. 対象キャラと表示先（スコープを絞る）

- 対象は **第1世代の相手校エース6人**（帝都のエース＋風間 駿／岩崎 剛／大熊 鉄平／東雲 悠真／北原 蒼汰）。名前・設定が固定で、作り直しの無駄がない。
- 表示先は **対戦確認のキーマン対比と、試合中のカットインだけ**。ここが作中で一番大きく顔が出る場所で、効果測定がしやすい。自校の自動生成選手・一覧の小アイコンは現行 SVG のまま（ハイブリッド）。
- 生成物はバストアップ（胸から上）・背景は単色または透過に寄せ、現行の立ち絵枠にそのまま収まる形にする。

## 3. Higgsfield 側の前提（2026-10-29 時点の公開情報）

- **Soul ID**：参照画像（20枚以上推奨）からキャラの同一性を学習し、画像・動画の生成で再利用できる仕組み。作成 25 クレジット、学習は数分。有料プランで利用可。自撮り等の実写前提の設計なので、イラスト調でどこまで効くかは本試作の検証対象。
- **画像モデル**：Soul 2.0（実写・編集寄り）、Nano Banana 2／Pro（参照画像を使った一貫性が強い、1枚 2 クレジット程度）などが同一クレジットで使える。画風は **Moodboard**（参照画像集で作風を固定）で寄せる。
- **Claude 連携**：公式に **MCP と CLI** があり、Claude Code から生成を回せる（＝「Claude Code で巻き取る」構成が公式に可能）。ただし Unlimited 生成の特典は Web（higgsfield.ai）上での生成のみで、MCP／CLI 経由には適用されない。
- **料金**（情報源により幅あり・改定も頻繁。契約前に公式 pricing ページで再確認）：Starter 月額 $15〜19（200〜270 クレジット）、Plus 月額 $39〜59（1,000〜1,200 クレジット）。クレジットは繰り越しなし。**年額プランは返金不可なので試作では使わない（月額のみ）**。

## 4. 進め方（ステージ制・途中で止められる）

### Stage 0：準備（コスト 0）
- Higgsfield アカウント作成と **月額プラン** の契約（支払いは Takada 本人がブラウザで実施。Muse は手順を案内し、Secure Vault 運用に乗せる）
- MCP／CLI 接続の可否を確認（使えなければブラウザ操作で代替＝ChatGPT イラスト運用と同じ形）。なお API は別アカウント・別残高制なので使わず、プランのクレジットを使う MCP／CLI が本命
- ~~商用利用条件を規約で確認（Q5）~~ → **確認済み（2026-10-29）**：利用規約 4.4 で Higgsfield は生成物の所有権を主張せず、商用利用も制限しない。クレジット表記も不要、解約後も権利は残る。注意点は3つ：①無料プランの書き出しには透かしが入るため、商用前提なら有料プラン必須（本試作は有料前提なので問題なし）②生成物が他人の生成と偶然似る可能性は排除されない（独占性なし）③Enterprise 以外は入出力がモデル学習に使われ得る（削除すれば将来分は止まる）。生成物を別 AI の学習に使うことは禁止だが、本用途には無関係

### Stage 1：画風探索（目安 30 枚・60 クレジット前後）
- 画風アンカー：既存の ChatGPT 場面イラスト（タイトル絵・優勝絵）の色味とタッチに寄せる。Moodboard に既存イラストを登録
- プロンプト雛形を固定する（画風ブロック＋年齢／体格／髪型／学校カラージャージの可変ブロック）。ジャージ色は v0.18 の学校カラー（帝都=黒、青葉=緑、西=赤、工業=橙、東都=青、北辰=紫）
- ここで「イラスト調が写真寄りに崩れる」問題が出たら、Nano Banana Pro の参照生成に主軸を移す

### Stage 2：本生成（6人分）
- 各キャラ「キャラシート（1枚に複数アングル）→ バストアップ本番 2〜3 テイク」の順で生成し、歩留まりを記録する
- 一貫性が弱いキャラは Soul ID 化（25 クレジット／人）を試す。6人全員ではなく、崩れるキャラだけに使う

### Stage 3：加工と組み込み（コスト 0、Muse 作業）
- 切り抜き・リサイズ・圧縮をローカルで実施。1枚 30KB 前後を目安（play.html の容量残量が約150KB しかないため、超過する場合はファイル参照方式への切替を別途判断）
- 組み込みは「エース（学校×世代）→ 画像」の差し替えマップ方式で、SVG 立ち絵の仕組みは残す（いつでも戻せる）
- 監査はいつもの 932×430／932×380・3点ゼロ＋ qa 回帰を通し、v1.0 への小更新として push・公開リンク反映

### Stage 4：判定
- Takada の目視で go／no-go を決める（下記の合格基準）。ダメなら SVG に戻して終了し、予算は温存する

## 5. 予算配分（上限 20,000 円）

| 項目 | 金額 | 備考 |
|---|---|---|
| プラン1か月（Starter 月額） | 約3,000円 | $19 前提。クレジットが足りなければ Plus（約7,400円）へ |
| 追加クレジット／2か月目 | 〜7,000円 | Stage 2 の歩留まりを見て判断 |
| 予備（勝ち筋が見えた時の本採用分） | 10,000円 | 試作の段階では使わない |

**試作で実際に使うのは最大でも 1 万円まで**を目安にし、残りは「効くと分かった後」のために残す。

## 6. 合格基準（go の条件）

1. 6人を並べて画風の統一感がある（Takada の目視判定）
2. キーマン対比とカットインで、SVG の自校選手と並んでも破綻しない（または対比側は相手だけ実絵でも成立する）
3. 採用単価が 1 人あたり 1,500 円以内に収まる（量産可能性の目安）
4. 商用利用条件に問題がない（**2026-10-29 確認済み**：有料プラン前提で問題なし）
5. 組み込み後の監査（両寸法・3点ゼロ）と回帰テストが通る

## 7. リスクと代替

- **画風が実写寄りに抜けない**：Soul 系は実写・編集写真が本領。イラスト調が安定しなければ、参照生成（Nano Banana Pro）に寄せる。それでもダメなら試作は失敗として止め、残予算はパーツキット外注（調査レポートの本命案、推定8〜20万円）の頭金として温存する。
- **価格・仕様の変動**：Higgsfield は料金改定が頻繁。契約直前に公式ページで再確認する。クレジットは繰り越せないので、生成は1か月内に集中させる。
- **モデルの画風ドリフト**：採用した絵はファイルとして手元に残るため、将来モデルが変わっても既存資産は無事。量産は「同じ雛形＋Moodboard」で再現性を担保する。
