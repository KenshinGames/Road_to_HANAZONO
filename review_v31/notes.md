## 描き方

- 生成 AI は使わない（Higgsfield は無料枠で書き出しに透かしが入り本番に使えない。契約しない決定）。
- `tools/paint_scenes.py`（numpy と Pillow だけ。場面ごとに固定のシード）で 1600×800 の絵を描く。
  - 遠近法のカメラ：地面・ライン・ポスト・観客席を m の世界から写す（観客は席の段ごとに人の形を 2 倍の細かさで作って縮める）。
  - 雲・木・花の房（紫陽花は小花の集まり）・うろこ雲は、乱数の形に光の向きの陰影をつける。水たまりは上の景色を地平線で折り返して映す。
  - 仕上げに光のにじみ・周辺減光・粒子（JPEG の容量のため控えめ）。
  - 横断幕の字は Dela Gothic One（OFL。入手は tools/embed_fonts.py と同じ npm パッケージ）。
- `--embed` で style.css の `.photo-<key>`（data URI）を書き換える。絵を直すときはスクリプトを直して描き直す。
- 置き方：主役（ポスト・木・スタンド）は中央寄り、左上は空や屋根の静かなところ（週の見出しと札が乗る）。狭い枠（月頭の左・対戦確認の帯）は中央が切り出される。

## 試作で直したこと

- 地面を全画素で塗る処理が、先に描いた観客席の下の段を上書きしていた → 地面と線を先に、スタンドを後に描く順に。
- 雲の濃さの初期値が 0 で、乱数が正のところ全部に雲が出た → 初期値を十分に小さく。
- 木の葉・花のかたまりを足し算で重ねると飽和して四角く塗られた → 「どれかに含まれる」で合わせ、範囲は全部のかたまりから決める。
- 桜の枝が下へ垂れて花のない枯れ枝に見えた → 枝の向きを上半分に制限。
- 紫陽花がドットの塊に見えた → 4 枚の花びらの小花を並べた丸い房に。水たまりが紙切れに見えた → 上の景色を映す。
- うろこ雲が絵の具の飛び散りに見えた → 空の面に並べた小さな雲（遠いほど小さく詰まる）に。太陽の光の筋が地面にかかった → 空だけに。
- 県予選の左の照明塔の光が週の見出しの真下に来た → 照明塔を中央寄りへ。花園の太陽のにじみが大きすぎた → 芯を小さく。
- 容量：q84 では 5 枚で約1.1MB → q80・粒子を半分にして約0.87MB（1 枚 145〜238KB）。
